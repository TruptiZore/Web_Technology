Tools for Angular -----
    1. node.js - run js code outside the browser.
    2. npm - node package manager 
    3. Angular CLI (Command Line Interface, used to crete and manage angular App.)


Steps --
    1. node -v
    2. npm install -g @angular/cli
    3. ng new my-first-app
    4. to run src ->> ng serve / ng s / ng serve -o
       ( our main file is src-> index.html )
