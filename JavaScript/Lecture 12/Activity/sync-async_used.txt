Where Synchronous Programming is Used ------

        - Banking transactions (money deduction → update balance → receipt)
        - Login authentication
        - Data validation and processing
        - Used when order matters and tasks depend on each other.


Where Asynchronous Programming is Used -----

        - API calls
        - File uploads/downloads
        - Chat applications
        - Web servers (Node.js)
        - Used when waiting for I/O operations and handling multiple users.


🧠 Simple Industry Rule -----

| Use Synchronous     | Use Asynchronous     |
| ------------------- | -------------------- |
| When order matters  | When waiting for I/O |
| Critical operations | API calls            |
| Small tasks         | Large tasks          |
| Financial systems   | Web servers          |


🎯 Strong Interview Answer -------

    - Synchronous programming is used when operations depend on each other and must execute in order, like banking transactions.

    - Asynchronous programming is used for I/O operations like API calls, file handling, and real-time systems to improve performance and scalability.


🎯 One-line interview answer -------

    - Synchronous is used for dependent and critical operations.
    - Asynchronous is used for I/O tasks and scalable web applications.
